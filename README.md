For Minecraft 1.21.1 with NeoForge, but should work with 1.21 as well. The entity highlighting feature is a buggy mess and unfinished, but the rest works very well.

Install from the [releases](https://github.com/lunanerdderg/MinecraftBoogieWoogie/releases/latest/).
